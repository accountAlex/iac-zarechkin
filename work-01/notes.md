# Журнал ручных действий

## Создание виртуальной машины через веб-консоль

1. Открыт сервис Compute Cloud.
2. Открыт раздел «Виртуальные машины».
3. Выбрано создание виртуальной машины.
4. Задано имя `zarechkin-11-web-manual`.
5. Добавлена метка `created-by=console`.
6. Выбран образ Ubuntu 24.04.
7. Выбрана зона `ru-central1-b`.
8. Выбран тип диска HDD.
9. Установлен размер диска 20 ГБ.
10. Выбрано 2 vCPU.
11. Установлена гарантированная доля vCPU 20%.
12. Установлено 2 ГБ RAM.
13. Включён режим прерываемой виртуальной машины.
14. Выбрана подсеть `default`.
15. Публичный IP-адрес установлен автоматически.
16. Выбран способ доступа по SSH-ключу.
17. Указан логин `student`.
18. Добавлен SSH-ключ `zarechkin-11-mac`.
19. Отключено резервное копирование.
20. Создана виртуальная машина.
21. Выполнено подключение к машине по SSH.
22. Обновлён список пакетов.
23. Установлен nginx.
24. Проверен статус nginx.
25. Проверена доступность страницы nginx в браузере.
26. Страница nginx персонализирована словом `devlab` и именем хоста.
27. Проверена персонализированная страница в браузере.
